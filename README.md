# Portofolio Profesional — Ridwan Malik (Malik)
> **Senior Fullstack Developer & Software Architect**

Website portofolio modern berskala enterprise yang dirancang khusus untuk memikat technical recruiter, hiring manager, dan engineering lead. Dibangun menggunakan **React 19**, **React Router v7 (SPA)**, **Tailwind CSS v4**, **Vite**, dan **Lucide Icons**, berpedoman langsung pada rekam jejak resmi **CV.pdf** serta dua proyek unggulan: **Hadirin** dan **Kerja Cerdas**.

---

## 🌟 Fitur Baru & Pilihan Tampilan

1. **Dual Theme (Light & Dark Mode)**:
   - **Default: Light Mode** (tampilan bersih, modern, dan profesional dengan kartu putih, aksen indigo, dan kontras tajam).
   - **Dark Mode**: Skema gelap futuristik dengan pencahayaan ambient glow dan glassmorphism.
   - Dilengkapi tombol toggle matahari ☀️ / bulan 🌙 di header dengan persistensi pilihan di `localStorage`.
   - Menggunakan skrip pencegah kedipan (anti-FOUC) saat memuat halaman.
2. **Dual Language (English & Bahasa Indonesia)**:
   - **Default: English (EN)** (dioptimalkan untuk recruiter global dan perusahaan multinasional).
   - **Bahasa Indonesia (ID)**: Terjemahan lengkap dan profesional untuk seluruh halaman, studi kasus, dan formulir.
   - Dilengkapi tombol toggle `🌐 EN / ID` di header untuk beralih bahasa dalam 1 klik tanpa reload halaman.

---

## 🚀 Fitur Utama Lainnya

1. **Konsep Single Page Application (SPA) Murni**: Navigasi halaman instan tanpa refresh menggunakan `react-router-dom`.
2. **Pilar Khusus Recruiter & Hiring Manager**:
   - **Metode STAR (Situation, Task, Action, Result)** pada setiap studi kasus proyek.
   - **Metrik Pencapaian Terukur**: +40% efisiensi tim/proyek di PT Teltics Media, +30% optimasi loading time di PT Edrus Strategi Digital.
   - **Banner Recruiter**: Tombol instan 1-klik unduh CV asli (`/cv.pdf`), salin email, dan kirim pesan.
3. **Studi Kasus Proyek Mendalam**:
   - **Hadirin**: AI-Powered Multi-Tenant Workforce & Smart Attendance SaaS (Geofencing GPS, Cross-Midnight Roster, Granular RBAC 35+ permissions, AI Workforce Co-pilot).
   - **Kerja Cerdas**: End-to-End Intelligent Procurement Orchestration Platform untuk PT AKM Group (Telegram Gateway, Qdrant Vector Semantic Normalization 650+ SKU, Local SLM Qwen/llama.cpp, Temporal Workflow Engine, Vision-OCR 3-Way Line Matching).
   - **Interactive Lightbox Modal**: Fitur zoom & fullscreen galeri screenshot untuk seluruh tangkapan layar proyek.
4. **Resume Interaktif & PDF Asli**:
   - Tampilan CV interaktif ATS-friendly yang siap cetak (`window.print()`).
   - Akses langsung unduh dan pratinjau file asli `cv.pdf`.
5. **Formulir Kontak Cepat**:
   - Pilihan template pesan siap pakai untuk recruiter ("Undangan Interview Senior Role", "Diskusi Arsitektur & Kolaborasi").

## 🏃 Cara Menjalankan Secara Lokal

1. **Pastikan Node.js terpasang** (disarankan Node.js v18+ atau v20+).
2. **Jalankan Development Server**:
   ```bash
   npm run dev
   ```
   Buka browser di `http://localhost:3000` (atau port yang tertera di terminal).

3. **Build untuk Produksi**:
   ```bash
   npm run build
   ```

4. **Preview Hasil Build Produksi**:
   ```bash
   npm run preview
   ```
